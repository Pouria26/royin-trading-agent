## Implementation

- `src/royin/boxapi_pool.py` appends a one-time, hash-bound authority to the original SQLite budget. Three additive tables track authority, attribution and credential health. Original `model_reservations` schema, all old rows, credit grants and role scopes remain intact. The authority accepts only allowlisted non-secret member fields.
- `src/royin/model_budget.py` validates the original anchor, policy/model, pool authority and private credentials before HTTP. It atomically reserves both aggregate and member allowance with `BEGIN IMMEDIATE` and FULL synchronous writes, then selects the least-consumed fraction of the remaining member budgets. Request hooks inject the chosen credential; neither model prompts nor recorded request bodies receive it. Legacy funded paths cannot reuse a pooled member to bypass attribution.
- The active path has `daily_limit=null`. Aggregate cost, per-key cost, finite HTTP/token/role limits and original mission expiry remain. HTTP401/402/403 disable that member;429 gives a15-minute cooldown, other response errors a60-second cooldown. Failure never refunds a reservation or initiates an automatic retry. Another scheduled request may select a healthy member. The fallback behavior is regression-tested; production has not encountered a failed member yet.
- Private credentials reside at `/state/data/boxapi-pool-keys.private.json`,0600, outside the immutable source and build archive. Missing original DB, missing keys or mismatched authority fails before model HTTP. No environment credential replacement or financial config migration was needed.
- `src/royin/runtime_release.py`, `scripts/run_fresh_service.py` and `scripts/run_market_paper.py` bind the pool to the append-only source transition and orchestrator. `src/royin/agent.py` adds only non-secret funding fingerprints to recorded model traces. The new pooled role scope starts at the ORIGINAL mission start time, preserving its deadline. Old scopes and their consumed counters stay exact, rather than being reset or relabeled.
