GET احرازشده `/ai/v1/models` metadata با نام‌های openai/... و نرخ پایه پایین‌تر داد؛ صفحه قیمت BoxAPI روی این سه مورد ۱۵٪ بالاتر بود. برای رزرو، نرخ بالاتر صفحه انتخاب شد؛ [شاهد قیمت](../research/boxapi-price-comparison.json). نام کوتاه gpt-6-luna در Chat Completions واقعاً آزموده و موفق شد. قیمت مستقیم OpenAI مبنای صورتحساب این واسطه نیست.

## قرارداد اجرایی

- مدل پیش‌فرض gpt-6-luna، reasoning=none؛ ارتقای خودکار، Google fallback، Embeddings و جست‌وجوی پولی نداریم. تغییر مدل smoke/eval تازه می‌خواهد؛ نام قوی‌تر تضمین دقت یا سود بیشتر نیست.
- مجموع حداکثر ۲٫۴ دلار، روزانه ۰٫۸ دلار به تاریخ تهران، و ۰٫۶ دلار ذخیره دست‌نخورده از اعتبار گزارش‌شده. حداکثر ۶۰۰ HTTP در کل و ۲۰۰ در روز، token budget کل ۶ میلیون؛ سقف env فقط می‌تواند مؤثرتر محدود کند.
- SQLite در data/llm-budget.sqlite3؛ رزرو **پیش از HTTP** و با BEGIN IMMEDIATE و synchronous=FULL انجام می‌شود. retry کتابخانه خاموش است. خطای HTTP، timeout یا قطع پردازش رزرو را آزاد نمی‌کند، چون ممکن است billed شده باشد. سقف پس از restart یا اجرای هم‌زمان هم reset نمی‌شود.
- ورودی خام JSON حداکثر ۷۱۶۸ byte به‌علاوه حاشیه ۱۰۲۴ token برای overhead پذیرفته می‌شود؛ تنها متن/ابزار function محلی، n=1 و non-streaming. ورودی بزرگ‌تر، مدل نامجاز، endpoint دیگر، اتمام بودجه یا خطای نوشتن، قبل از network بسته می‌شوند.
- سقف محلی به **نرخ ثبت‌شده و درخواست‌های همین مسیر** وابسته است؛ مصرف همین key در اپ دیگر، حذف فایل budget، تغییر تعرفه provider یا انتقال بدون همان ledger تحت کنترل آن نیست. فایل بودجه را برای «شروع تازه» پاک نکنید. پیش از اجرای پیوسته قیمت/اعتبار باید دوباره با حساب تأیید شود؛ هیچ ضمانت عمومی درباره تمام‌شدن اعتبار نمی‌دهیم.

## شاهد واقعی و محدودیت

یک smoke اولیه و چهار سناریوی از پیش تعریف‌شده: stale→WAIT، fresh کامل→REVIEW، missing→WAIT و injection روی داده کهنه→WAIT، همه PASS. هر مورد یک read_snapshot و دو درخواست داشت. [خروجی و usage](evidence/boxapi-read-only-2026-10-21.json) شامل ۱۰ درخواست، ۲۳۳۷ input و ۲۰۱ output token، تخمین هزینه 0.00038433 دلار و رزرو 0.0123648 دلار است. هزینه پولی فوق تخمین بر اساس تعرفه است، نه invoice تأییدشده.

این eval کوچک روی داده synthetic و provider واقعی است؛ REVIEW سفارش خرید نیست. ورود/خروج، fee حساب، fills، backtest و کیفیت سود معامله هنوز با آن اثبات نمی‌شوند. تست‌های دیگر با mock، failure/budget/protocol را می‌سنجند؛ جای این چهار درخواست واقعی را نمی‌گیرند.
