# مدل و بودجهٔ اجرایی BoxAPI

**ادامه روی میزبان تازه:** همه entrypointهای پولی DB اصلی و دارای سابقه را با `require_existing=True` می‌خواهند. مسیر پیش‌فرض به ریشهٔ package متصل است، نه cwd؛ نبود/خرابی/خالی‌بودن DB، BLOCKED است و reserve/RoleRunEnvelope آن را بازسازی نمی‌کنند. بازیابی سازگار DB و WAL و تحویل مالکیت لازم است؛ داشتن کلید به‌تنهایی مجوز ledger صفرمصرف نیست. bootstrap با path صریح در تست‌های مصنوعی، مجوز reset بودجهٔ این پروژه محسوب نمی‌شود.

مرجع عددی `config/llm-budget-policy.json` و سقف صریح `.env` است. مدل فعلی `gpt-6-luna`، Chat Completions و `reasoning_effort=none`؛ fallback خودکار به Google یا OpenAI مستقیم نداریم. تغییر مدل به smoke و ارزیابی تازه نیاز دارد، نه فرض سود بیشتر.

| محدودیت | سیاست فعلی |
|---|---|
| input/output رزروشده در هر HTTP | ۳۲۷۶۸ / ۱۰۲۴ token |
| سقف کل/روزانه | USD 2.40 / 0.80؛ تاریخ روزانه تهران |
| درخواست کل/روزانه | ۶۰۰ / ۲۰۰ |
| scope نقش‌های جدید | ۴۸ اجرای نقش، ۹۶ HTTP، USD 0.50 رزرو |
| scope قدیمی | سقف و شمارندهٔ ذخیره‌شدهٔ خودش؛ migration آن را افزایش نمی‌دهد |

برای Luna با نرخ ثبت‌شدهٔ input=0.115 و output=0.575 دلار در میلیون، رزرو بدترین حالت هر HTTP برابر USD0.00435712 است. این نرخ snapshot سیاست است، نه تأیید دائمی تعرفه یا صورتحساب provider. کاربر مصرف واقعی کمتر از پنج سنت گزارش کرده؛ آن را با مجموع رزرو محافظه‌کارانه برابر ندانید.

`ModelBudget` پیش از هر HTTP با SQLite و تراکنش پایدار رزرو می‌کند؛ retry خودکار خاموش است. timeout، خطا یا مرگ فرایند refund خودکار ندارد. `LLM_TOKEN_BUDGET` از env خوانده می‌شود و سقف جداگانه است؛ مقدار example لزوماً مقدار میزبان نیست. parser درخواست نیز اندازهٔ بدنه و حاشیه را محافظه‌کارانه با این سقف می‌سنجد.

فایل `data/llm-budget.sqlite3` را برای restart، انتقال میزبان یا رفع BLOCKED حذف/صفر نکنید. مصرف همین کلید در برنامهٔ دیگر و تغییر تعرفه بیرون از این دفتر است. کلید، raw header، شناسهٔ حساب و `.env` نباید وارد مدل، Git یا ویدئو شوند.

بودجه مانع فنی بی‌دلیل تحلیل نمی‌شود؛ دامنهٔ فعلی برای آزمون چندساعته تعیین شده است. بیشتر خرج کردن یا مدل بزرگ‌تر به‌تنهایی alpha ایجاد نمی‌کند. بودجهٔ مدل، سقف سرمایهٔ معاملاتی و هزینهٔ واقعی سفارش سه موضوع متفاوت‌اند.
