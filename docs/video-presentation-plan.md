## ۴. دستورالعمل و چک‌لیست ضبط ویدئو

### ۴.۱. آماده‌سازی قبل از ضبط (Pre-flight Checklist)
- [ ] اجرای سرور داشبورد در یک ترمینال پس‌زمینه:
  ```powershell
  .\.venv\Scripts\python.exe -X utf8 dashboard/server.py --port 8765
  ```
- [ ] باز کردن مرورگر کروم یا اج روی آدرس `http://localhost:8765` با بزرگنمایی ۱۰۰٪ یا ۱۱۰٪ برای خوانایی بهتر متن.
- [ ] باز کردن ترمینال PowerShell در ریشه مخزن (`d:\royin-trading-agent`) با فونت واضح (حداقل سایز ۱۶).
- [ ] اطمینان از بسته بودن فایل‌های حاوی کلید مانند `.env` و تب‌های مرورگر متفرقه.
- [ ] تست ضبط میکروفون (عدم وجود اکو، صدای کیبورد مکانیکی بیش از حد، یا قطعی صدا).

### ۴.۲. دستورات آماده برای کپی/پیست سریع حین ضبط
1. **دستور آماده‌سازی پایلوت و گیت فروش‌پذیری:**
   ```powershell
   .\.venv\Scripts\python.exe -m scripts.run_live_pilot --prepare
   ```
2. **دستور اجرای تست‌های اصلی:**
   ```powershell
   .\.venv\Scripts\python.exe -m unittest discover -s tests -v
   ```
3. **دستور اجرای تست‌های داشبورد:**
   ```powershell
   .\.venv\Scripts\python.exe -m unittest discover -s dashboard/tests -v
   ```
