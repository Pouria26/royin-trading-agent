# شواهد واقعی آماده‌سازی

**T01، ۲۰۲۶-۱۰-۲۱:** package/config/CLI ساخته و ۲۸/۲۸ تست در محیط فعلی، نصب پاک از lock و wheel نصب‌شده گذشت؛ صفر fail/skip. Ruff و compileall با اضافه‌شدن src موفق‌اند. این به‌روزرسانی، عبارت‌های تاریخی «Build/CLI نداریم» را فقط برای CLI اعتبارسنجی supersede می‌کند؛ موتور، broker، AI واقعی و سودآوری هنوز تأیید نشده‌اند. همه liveها بسته‌اند. دستورهای دقیق جدید در AGENTS.md و گزارش AC/revision در TASKS.md است.

نصب پاک این گام در پوشه موقت جدا با Python 3.12.15، `uv pip sync --python <clean-python> requirements.lock` و سپس `uv pip install --python <clean-python> --no-deps --editable .` انجام شد. `uv build --wheel` موفق و wheel خروجی با `--no-deps --reinstall` در همان محیط نصب و تست شد. `check-config` روی env نمونه و محلی، `VALID_CONFIG_ONLY` داد؛ هیچ شبکه یا سفارش/SQLite ایجاد نمی‌کند. build backend فقط برای packaging است؛ وابستگی runtime تازه‌ای اضافه نشد. فرمان‌های help هر دو probe هم موفق‌اند.

اجرای عمومی تازه در **۱۵:۲۶:۰۳ UTC / ۱۸:۵۶:۰۳ ایران**: شش نمونه DEGRADED و exit 1؛ hash همه پاسخ‌ها و یافته‌های جدول زیر با دریافت قبلی یکسان بود. smoke `probe_model.py --run` دوباره **BLOCKED و exit 2** بود؛ GOOGLE_API_KEY نبود و هیچ درخواست مدل ارسال نشد. مدل/حساب/استراتژی/live همچنان تأییدنشده‌اند. برای رفع مانع، کلید فقط در .env محلی و سپس دستور بخش اقدام بعدی؛ PASS/WAIT/read_snapshot شاهد compatibility است، نه سود.

**تکمیل بعدی در ۲۰۲۶-۱۰-۲۱:** محدودیت بازار اکنون طبق متن/تصویر تازه پوریا در docs/market-access-policy.md و config/wallex-credit-market-policy.json ثبت است؛ مجهول قبلی «نبود قاعده/فهرست بازار» در گزارش اولیه با این اطلاعات superseded شد. فقط اسپات بدون لوریج؛ تطبیق روز حساب اختصاصی هنوز انجام نشده. بعد از اضافه شدن سه تست snapshot، کل مجموعه فعلی **۱۵/۱۵ passed با صفر fail/skip** و Ruff موفق شد. این اجرای تازه در .venv فعلی است؛ نصب پاک ۱۲ تست جدول پایین مربوط به مرحله قبلی است و برای سه تست جدید ادعا نشده است. داده عمومی، مدل واقعی و حساب خصوصی در این تغییر دوباره آزموده نشدند؛ هیچ سفارش ارسال نشد.

۲۰۲۶-۱۰-۲۱؛ این گزارش **آمادگی مستندات و ابزار پژوهش** است، نه نتیجه موتور معاملاتی. ابزارها، tests، lock و گزارش JSON در همان commit آماده‌سازی نگه‌داری می‌شوند؛ revision از `git log -1 --oneline` در checkout تحویلی قابل مشاهده است. بعد از تغییر کد، نتیجه قبلی خودکار به نسخه جدید تعمیم نمی‌یابد.

## منابع بررسی‌شده

بریف کامل و transcript ویدئوی پوریا، Blueprint محلی، Git و وابستگی‌ها، صفحه عمومی استارکوچ با HTTP مستقیم، مستندات رسمی عمومی والکس (حساب اعتباری، اسپات، کندل، depth، fee، ایجاد/لغو/استعلام و socket)، قابلیت‌های Pydantic AI/Google provider و LangGraph و مستندات دیسک/supervisor لیارا بررسی شدند. جزئیات بریف از متن پوریاست؛ صفحه عمومی آن‌ها را مستقلاً نمایش نداد. private بودن مخزن با GitHub API تأیید شد؛ visibility تغییر نکرده و push انجام نشده است.

فایل ویدئو قابل decode بود: ۳ دقیقه و ۵۴٫۶۱ ثانیه، 550×854، H.264 و صوت AAC؛ نمونه‌فریم‌ها بررسی شدند. تحلیل محتوایی از transcript ارائه‌شده پوریاست؛ شنیدن مستقل و تطبیق کلمه‌به‌کلمه صوت انجام نشد. ابزار decode در TEMP نصب شد و وابستگی موتور نیست.

## آزمون‌های اجراشده

Python 3.12.15؛ Pydantic AI slim 2.59.0؛ Pydantic 2.14.1؛ httpx 0.28.1؛ python-dotenv 1.2.4؛ Ruff 0.17.1. extra گوگل و وابستگی‌های حل‌شده در requirements.lock ثبت شده‌اند. یک محیط پاک موقت جدا با uv ساخته و از lock نصب شد.

| بررسی | نتیجه | چیزی که ثابت می‌کند |
|---|---|---|
| unittest در محیط موجود | **12 passed / 0 failed / 0 skipped** | ۷ تست profile، ۳ FunctionModel، ۲ تست no-key/no-run |
| unittest بعد از نصب پاک از lock | **12 passed / 0 failed / 0 skipped** | همین ابزارها در محیط تازه کار می‌کنند |
| Ruff با ruff.toml محلی | PASS | scripts و tests؛ src موتور هنوز وجود ندارد |
| compileall روی scripts و tests | PASS | صحت نحوی، نه درستی معامله |
| --help هر دو probe | PASS | CLIهای آماده‌سازی قابل فراخوانی‌اند |
| probe_model.py --run با key خالی | **BLOCKED، exit 2** | هیچ درخواست مدل فرستاده نشد |
| کنترل .env و git check-ignore | PASS | .env محلی ساخته شده و key مدل خالی بود؛ .env، data و ویدئو ignored هستند |

FunctionModel نشان داد نتیجه ابزار به خروجی typed می‌رسد، action نامعتبر پذیرفته نمی‌شود و سقف turn حلقه را متوقف می‌کند. این‌ها **کیفیت استدلال Gemini، سودآوری یا مدیریت سرمایه موتور هنوز ساخته‌نشده** را ثابت نمی‌کنند. banner کتابخانه و پیام debug event-loop مشاهده شد؛ خطای تست نبودند. دستورهای واقعی در AGENTS.md هستند؛ Build/Run محصول فعلاً وجود ندارد.

## یافته مهم داده تاریخی

اجرای واقعی `scripts/audit_market_data.py`، بدون کلید و فقط GET عمومی؛ [گزارش کامل](../research/market-data-audit.json) شامل query، source URL، fetched_at و SHA256 هر پاسخ است. rawها در data/research محلی ignored هستند. آخرین گزارش: ۲۰۲۶-۱۰-۲۱ ساعت ۱۵:۲۶:۰۳ UTC؛ دریافت قبلی ۱۳:۴۵:۲۴ UTC بود و hashها برابرند. بازه‌ها [start,end) و برحسب UTC هستند.

سه نماد عمومی، دو پنجره تاریخی، درخواست resolution=15. **هر شش مورد DEGRADED؛ exit 1**. این نتیجه عمداً سبز نشده است و نمادهای عمومی allowlist چالش نیستند.

| بازار / پنجره اکتبر ۲۰۲۶ UTC | ردیف انتخاب‌شده | فاصله غالب timestamp | ردیف گمشده روی شبکه یک دقیقه |
|---|---:|---:|---:|

| BTC / ۸ تا ۱۵ | 10078 | 60 ثانیه | 2 |

انتظار یک پنجره هفت‌روزه ۱۵ دقیقه‌ای ۶۷۲ ردیف است. در ردیف‌های دریافت‌شده duplicate، زمان نامرتب، خارج از بازه پس از کنار گذاشتن boundary، یا OHLC/مقدار نامعتبر دیده نشد. حجم صفر جدا ثبت شده و به‌تنهایی خرابی داده تلقی نشده است؛ برای نقدشوندگی/fill مهم است. علت گپ‌ها هنوز معلوم نیست.

کنترل روی BTCTMN در ۱ اکتبر با from/to یکسان:

| resolution | ردیف [start,end) | فاصله timestamp | وضعیت |
|---|---:|---:|---|
| 1 | 1440 | 60 ثانیه | PASS برای شبکه یک دقیقه |
| 15 | 1440 | 60 ثانیه | DEGRADED؛ SHA256 دقیقاً برابر پاسخ resolution=1 |
| 60 | 24 | 3600 ثانیه | PASS برای شبکه یک ساعت |

**تفسیر محدود:** resolution=15 در این دریافت مطابق معنای مستند نبود. fallback محتمل است، علت داخلی سرویس اثبات نشده؛ نتیجه به همه زمان‌ها/endpointها تعمیم داده نشود. استفاده بی‌بررسی از این داده به‌عنوان ۱۵ دقیقه، اندیکاتور و افق استراتژی را مخدوش می‌کند؛ ریسک آن برای بک‌تست بالاست.

**اقدام T02:** cadence واقعی در loader assertion شود. برای ۱۵ دقیقه، پارامتر تأییدشده پیدا شود یا داده یک دقیقه با aggregation صریح OHLCV و تست کندل کامل/causality تجمیع شود. bin ناقص/gap flag شود؛ forward-fill بی‌صدا ممنوع. کندل ساعتی فعلاً فقط نامزد پژوهش تأییدشده از نظر cadence است، نه استراتژی مناسب یا سودده. ابزار آماده‌سازی خودکار resample نمی‌کند.

## اقدام بعدی و محدودیت

پوریا مقدار `GOOGLE_API_KEY` را فقط در .env محلی بگذارد. مدل از قبل gemini-3.5-flash-lite است. Coding Agent سپس این دستور را اجرا کند:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\probe_model.py --run
```

انتظار سالم: PASS، action=WAIT، evidence_id=SYNTHETIC_STALE_1 و یک read_snapshot. هر خطای دسترسی/سهمیه یا رفتار متفاوت FAIL است. probe حداکثر دو turn، یک ابزار، سقف output tokens و deadline سی ثانیه دارد؛ بدون سفارش است و ممکن است هزینه کوچک مدل داشته باشد. بودجه آزمایش انبوه هنوز مشخص نیست.

گام Coding Agent: T01 و T02 با یافته cadence → برش کامل شبیه‌سازی T03–T06 → بک‌تست واقعی T07 → سایه T09. فردا حساب اختصاصی، شناسه، محدودیت بازار و fee از منبع رسمی راستی‌آزمایی شود. **هیچ معامله واقعی، استراتژی سودساز، بک‌تست موتور، اجرای سایه موتور یا deployment در این مرحله تأیید نشده است.**
